# 酒店 PMS 收银 Agent 指南

## 系统环境

- **PMS 数据库**：MySQL 8.0，连接串见环境变量 `PMS_DB_URL`
- **支付网关**：银联商务接口，地址见 `PAYMENT_GATEWAY_URL`
- **发票系统**：百望云电子发票，地址见 `INVOICE_SYSTEM_URL`
- **入住系统**：绿云 PMS / 住哲 PMS

## 计费规则

### 房费
- 入住日当天不计费
- 房费从入住次日开始计算
- 退房日 14:00 前：免当日房费
- 14:00-18:00 退房：加收 50% 房费（半日租）
- 18:00 后退房：加收 100% 房费（全日租）

### 服务费
- 标准费率：10%
- 协议单位（签约公司）：免收

### 增值税
| 服务类型 | 税率 |
|---------|------|
| 住宿服务 | 6% |
| 餐饮服务 | 6% |
| 商品销售 | 13% |

## 支付规则

- 单笔超过 **5000 元** 需值班经理审批
- 退款原路返回
- 现金退款超过 **5000 元** 需双人复核
- 单笔退款超过 **10000 元** 需值班经理审批
- 挂账仅限签约协议单位，需核对协议有效期
- 外币收取按当日现钞买入价折算

## 数据表结构

### 核心表
| 表名 | 说明 |
|------|------|
| `reservations` | 入住记录 |
| `folios` | 账单主表 |
| `charges` | 消费明细 |
| `payments` | 支付记录 |
| `invoices` | 发票记录 |
| `rooms` | 房间/房态 |
| `guests` | 客人信息 |
| `contracts` | 协议单位 |
| `shifts` | 交接班记录 |
| `audit_logs` | 审计日志 |

## 常见业务流程

1. **退房结算** → 调用 `check-out-settlement` 技能
2. **日结夜审** → 调用 `daily-close` 技能
3. **客诉处理** → 调用 `dispute-resolution` 技能

## 安全要求

- 所有金额计算必须双向校验
- 退款操作需二次确认
- 敏感信息脱敏（身份证、手机号）
- 审计日志不可删除，保留至少 2 年
- 不得向客人透露其他客人信息

## 注意事项

- 所有金额单位为人民币元，精确到分（两位小数）
- 时间统一使用 `Asia/Shanghai` 时区
- 操作员代号需记录在每笔交易中
- 异常情况优先保障客人体验
