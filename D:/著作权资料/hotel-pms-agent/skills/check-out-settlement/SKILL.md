# 退房结算技能

## 触发条件
当用户请求办理退房、结账、结算时激活。

## 执行步骤

### 1. 查询入住信息
使用 `query_guest` 获取客人信息和入住编号。

### 2. 计算总费用
使用 `calculate_checkout` 计算退房总费用，包含：
- 房费（含半日租/全日租判断）
- 杂费消费（minibar、餐饮、洗衣等）
- 服务费（协议单位免收）
- 增值税

### 3. 展示费用明细
向操作员展示完整费用明细，等待确认。

### 4. 处理支付
根据客人选择的支付方式调用 `process_payment`：
- 支付金额 > 5000 元时提醒需值班经理审批
- 退款操作需二次确认

### 5. 开具发票
如客人需要发票，使用 `generate_invoice` 开具：
- 核对发票抬头和税号
- 选择普票或专票
- 专票需完整信息（抬头+税号+开户行+账号+地址+电话）

### 6. 完成退房
- 释放预授权（如有）
- 使用 `update_room_status` 更新房态为「脏房」
- 打印结算单
- 记录审计日志

## 计费规则速查
- 14:00 前退房：免当日房费
- 14:00-18:00 退房：加收 50% 房费（半日租）
- 18:00 后退房：加收 100% 房费（全日租）
- 所有金额需双向校验

## 异常处理
- 账目不平：先挂账，记录差异，上报财务
- 客人拒付：通知值班经理，不做强制扣款
- 系统故障：手工单据记录，恢复后补录
