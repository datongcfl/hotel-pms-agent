# 日结技能

## 触发条件
当用户请求日结、夜审、结账汇总时激活。

## 执行步骤

### 1. 检查未结账单
查询所有未结算的账单，提醒操作员处理。

### 2. 汇总当日收入
按支付方式分类汇总：
- 现金收入
- 银行卡收入
- 移动支付收入（微信+支付宝）
- 挂账金额

### 3. 生成日结报表
使用 `generate_report` 生成：
- 收入汇总表
- 房态统计表
- 应收账款明细
- 发票开具记录

### 4. 校验账目
- 借贷是否平衡
- 现金账实是否相符
- 异常标记

### 5. 执行日结
调用 `daily_close`：
- 确认无遗漏的未结账单
- 归档当日数据
- 通知财务复核

## 日结检查清单
- [ ] 所有退房客人已结算
- [ ] 所有消费已录入
- [ ] 现金盘点与系统一致
- [ ] 发票开具无误
- [ ] 挂账已核对协议
- [ ] 应收账款更新
