# 客诉处理技能

## 触发条件
当用户报告客人投诉、纠纷、争议时激活。

## 常见投诉类型

### 1. 账单争议
**处理流程：**
1. 使用 `query_billing` 调出完整账单明细
2. 逐项与客人核对
3. 如有误录，使用 `adjust_balance` 调账（需二次确认）
4. 如需退款，使用 `process_payment` 退款（需审批）

### 2. 房费争议
**处理流程：**
1. 使用 `calculate_checkout` 重新计算费用
2. 核对入住/退房时间
3. 检查半日租/全日租判断是否正确
4. 如系统计算有误，手工修正并记录

### 3. 发票问题
**处理流程：**
1. 使用 `query_invoice` 查询发票记录
2. 如需作废，使用 `void_invoice`（需二次确认）
3. 重新开具正确的发票

### 4. 支付失败
**处理流程：**
1. 使用 `query_payments` 查询支付记录
2. 核对交易状态
3. 如扣款未成功，重新发起支付
4. 如重复扣款，发起退款

## 升级规则
- 折扣超过 10%：需值班经理审批
- 免单：需总经理审批
- 现金退款 > 5000：需双人复核 + 值班经理审批
- 涉及人身安全/违法：立即报警

## 处理原则
1. 先安抚情绪，再解决问题
2. 不轻易承诺免单/折扣
3. 所有调整操作必须记录审计日志
4. 涉及金额较大时必须升级处理
